工作流程

从截图到制造完成的全自动流水线

  1. 截图采集 — dxcam 从显存直接截取游戏窗口画面，零延迟
  2. OCR 识别 — Tesseract 对指定区域进行文字识别，判断当前物品名和剩余制造时间
  3. 智能决策 — 根据物品价值与制造队列，自动选择最优制造方案
  4. 材料购买 — 自动识别并点击购买所需材料（若材料不足则跳过）
  5. 启动制造 — 模拟点击制造按钮，自动输入制造数量
  6. 自动收集 — 监控制造完成，自动点击收集成品，循环下一轮
  7. 异常处理 — 声音提示+自动重试，挂机无忧

技术架构

📁 项目文件结构

DeltaForceSS-main/
├── main.py # 主程序入口
├── config.yaml # 核心配置: 物品列表、UI坐标、OCR参数

│ └── Tesseract-OCR/ # Tesseract OCR 运行时 (~60 DLL)

⚙️ config.yaml 核心配置

配置文件包含4大部门的所有可制造物品、游戏窗口UI坐标映射、OCR识别参数和制造队列定价数据。支持自定义添加新物品。

Python 3.10+Tesseract OCRdxcamWin32 API YAMLMouse SimulationPIL/Pillow

快速开始

  1. 安装 Python 3.10+ — 从 python.org 下载安装
  2. 安装依赖 — pip install -r requirements.txt
  3. Tesseract OCR — dist/ 目录已自带运行时，无需额外安装
  4. 调整分辨率 — 确保游戏使用 16:9 比例 (1920×1080 / 2560×1440 / 3840×2160)
  5. 管理员运行 — 右键以管理员身份运行 main.py（dxcam需要管理员权限）
  6. 打开制造页面 — 进入特勤处 → 升级制造，脚本自动开始工作
